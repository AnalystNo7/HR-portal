# BRIEF: Исключение нулей («не наблюдал») из расчётов методики

Дата: 2026-07-30

## Формулировка своими словами

В утверждённой шкале компании 0 означает «не могу оценить / не наблюдал
ситуаций для проявления поведения» — это отказ от оценки, а не низкий балл.
Сейчас код считает 0 обычной оценкой: он утягивает вниз все средние, ГЭП,
дисперсию и ловится «выбросом-низким баллом». Нужно исключить 0 из всех
расчётов, оставив его в интерфейсе опроса как легальный вариант ответа.
Заодно завести утверждённую шкалу 0–4 в сид как шаблон по умолчанию.

## Контекст

- Утверждённая шкала (от HR): 0 — не могу оценить/не наблюдал;
  1 — почти никогда не демонстрирует; 2 — в некоторых рабочих ситуациях;
  3 — в большинстве рабочих ситуаций; 4 — во всех, даже сверхсложных.
- Все расчёты — backend/src/oc360/results/results.service.ts (сбор баллов
  perLane :99–104, средние :110–131, respondentMeans :187–191,
  indicatorScores :181–185, scaleMin/scaleMax :195–199) и analytics.ts
  (avg :40, дисперсия, выбросы «низких баллов» :254 — порог scaleMin+1).
- Сид шкалы — prisma/seed-oc360.ts («Стандартная 1–5», нулевого пункта нет).
- Оси диаграмм берут min из пунктов шкалы: Report360View.tsx:336,
  SubjectPanel.tsx:165.
- Методика: RULE-004 (конвенции усреднения) в harness/REQUIREMENTS.md —
  «каждый балл с равным весом» — потребует дополнения «баллы 0 исключаются».

## Критерии успеха

- [ ] Балл 0 не участвует ни в одном расчёте: средние групп, итоговая
      средняя, ГЭП, дисперсия/разброс, средние респондентов, выбросы
      «низких баллов», индикаторные данные в промпт LLM.
- [ ] Если после исключения нулей у группы нет баллов по компетенции —
      её среднее = null («—»), группа выпадает из итоговой средней и ГЭПа
      этой компетенции (как сейчас у групп без респондентов).
- [ ] scaleMin для осей, промпта и порога выбросов = младший ненулевой
      пункт шкалы; пункт 0 остаётся в легенде шкалы и в опроснике.
- [ ] В сиде — утверждённая шкала 0–4 с формулировками HR; существующие
      данные сидом не перезаписываются (идемпотентность сохранена).
- [ ] Смоук: массив с нулями даёт то же среднее, что массив без них;
      все нули → null. tsc и build обоих приложений проходят.
