# BRIEF: Обратные вопросы 360 (методика v1.3)
Дата: 2026-08-31

## Формулировка своими словами
Новая матрица: у компетенции 6 вопросов — 3 прямых и 3 обратных (негативные
формулировки). Ответы на обратные должны учитываться инверсией (1↔4, 2↔3;
0 «не могу оценить» не инвертируется и в расчёт не входит). Итог компетенции —
среднее оставшихся баллов. Структура отчёта не меняется.

## Контекст
- Методика v1.3 (docx от методолога, финальный порог слепых зон 0,6).
- Почти вся расчётная часть v1.3 уже в коде (v1.2): исключение нулей
  (NO_OBSERVATION_SCORE), пороги 0,3/0,6, сильные >3,4 / развитие <3,0,
  целевой 3,0, рекомендации 4×4. Новое — только инверсия.
- Решено: инвертировать при сохранении ответа (respondent.service), не при
  чтении — тогда аналитика/отчёты не меняются вовсе. Форме респондента балл
  возвращается деинвертированным (функция симметрична).
- Респонденту пометка «обратный» не показывается (иначе реверс не работает);
  HR видит чекбокс/бейдж в шаблоне.
- «Версия 4 (пояснения)»: вопросы 4–6 каждой компетенции помечаются скриптом.

## Критерии успеха
- [ ] Ответы 4,4,4 (прямые) + 1,1,1 (обратные) → средняя компетенции 4,0
- [ ] Ответ 0 на любой вопрос не меняет среднюю (исключается)
- [ ] Респондент, открыв черновик, видит те баллы, которые нажимал
- [ ] В «Версии 4» у каждой из 9 компетенций ровно 3 обратных вопроса
- [ ] Запущенные ранее циклы не затронуты (флаг — в снапшоте цикла)

## Открытые вопросы
- Средняя при Δ≥0,6 — по всем или без самооценки? Ответ: по всем (как сейчас).
- Раздел «Расхождение между группами респондентов» — отложен: отдельная задача
  (меняет схему отчёта, промпт, части генерации, рендер, DOCX).
