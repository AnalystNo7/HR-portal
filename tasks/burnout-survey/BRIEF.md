# BRIEF: Опросы → «Выгорание (MBI)»: хранение результатов теста Маслач

Дата: 2026-08-17 (ответы человека подтверждены 17.08 со скриншотами)

## Формулировка своими словами

Сотрудники проходят тест Маслач (MBI, адаптация Водопьяновой/НИПНИ) на
psytests.org. Портал хранит замеры и показывает их в разделе «Опросы»
(вкладка «Выгорание (MBI)»): сотруднику — свои замеры и динамику, HR —
сводку по всем, руководителю — только уровни (без баллов) подчинённых.
MVP без интеграции: ручная форма + Excel-загрузка HR. Уровни и системный
индекс перегорания (ИСП) вычисляются кодом — в БД только сырые баллы.

## Методика (с эталонной страницы результата psytests, скриншот 17.08)

- Эмоциональное истощение: 0–54; уровни [0–15] низкий, [16–24] средний,
  [25–54] высокий.
- Деперсонализация: 0–30; [0–5] низкий, [6–10] средний, [11–30] высокий.
- Редукция проф. достижений: 0–48; шкала обратная — [37–48] низкое
  выгорание, [31–36] среднее, [0–30] высокое.
- ИСП (НИПНИ им. Бехтерева), 0–1: √((x₁²+x₂²+x₃²)/3), где x₁=ЭИ/54,
  x₂=ДП/30, x₃=1−РПД/48. Проверено на примере: (31, 11, 21) → 0,51 —
  совпадает со страницей результата.

## Решения человека (2026-08-17)

1. Способы ввода: ручная форма (сотрудник и HR) + Excel-загрузка HR.
   Автопарсинг и опросник в портале — не делаем.
2. Доступ: сотрудник — свои замеры; HR/admin — все; руководитель —
   уровни подчинённых БЕЗ баллов (и без ИСП-числа).
3. Храним только итоговые баллы трёх шкал + дата + источник + ссылка
   (опционально); уровни и ИСП вычисляются кодом.
4. UI: раздел «Опросы» становится рабочим, первая вкладка «Выгорание».
5. Пороги — со страницы результата (выше), константами в одной точке.
6. Сотрудник только вносит свои замеры; исправляет и удаляет — HR/admin.

## Критерии успеха

- [ ] Сотрудник: ссылка «Пройти тест», форма внесения (дата, 3 балла
      с валидацией диапазонов, опц. ссылка), список своих замеров
      с уровнями цветом и ИСП; чужие замеры сервер не отдаёт.
- [ ] HR: сводка по всем (последний замер: баллы, уровни, ИСП, дата),
      фильтр по подразделению, внесение за сотрудника, правка/удаление,
      Excel-загрузка с предпросмотром и подтверждением.
- [ ] Руководитель: список подчинённых с уровнями трёх шкал (без чисел).
- [ ] Смоук: ИСП(31,11,21)=0,51; уровни примера: высокий/высокий/высокое
      выгорание по редукции. Валидация диапазонов на сервере.
- [ ] tsc/build; db push (новая таблица, аддитивно — CON-003).
