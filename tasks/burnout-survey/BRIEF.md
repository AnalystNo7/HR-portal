# BRIEF: Опросы → «Выгорание (MBI)»: хранение результатов теста Маслач

Дата: 2026-08-17

## Формулировка своими словами

Сотрудники проходят тест Маслач на выгорание на внешнем сайте
(psytests.org). Портал должен хранить результаты замеров и показывать их
в разделе «Опросы» (сейчас заглушка) во вкладке «Выгорание (MBI)»:
сотруднику — его динамику, HR — сводку по всем. MVP без интеграции
с psytests: результат вносится вручную (форма с тремя баллами) или
массово Excel-файлом (HR). Уровни (низкий/средний/высокий) вычисляются
кодом по порогам методики — как и вся аналитика проекта (дух FR-002).

## Контекст

- Раздел /surveys — заглушка (StubPage), пункт меню есть.
- Паттерн массовой загрузки готов: импорт сотрудников (exceljs,
  предпросмотр errors/warnings, окно подтверждения — FR-018).
- Доступ и владелец на сервере — по образцу NFR-002 (IDOR-проверки).
- Внешний парсинг psytests в MVP не делаем (вариант отклонён при опросе;
  вдобавок из среды разработки домен недоступен — egress-прокси).
- Выгорание — чувствительные данные: доступ уже, чем у оценки 360.

## Решения человека (2026-08-17)

- Способы ввода: ручная форма (сотрудник и HR) + Excel-загрузка (HR).
- Доступ: сотрудник — только свои замеры; HR/admin — все; руководитель —
  ничего.
- Храним итоговые баллы трёх шкал (без ответов на вопросы).
- UI: раздел «Опросы» становится рабочим, первая вкладка — «Выгорание».

## Критерии успеха

- [ ] Сотрудник вносит замер (дата, три балла, опц. ссылка на результат)
      и видит свою динамику с уровнями; чужие замеры недоступны (сервер
      отклоняет — проверка владельца).
- [ ] HR: сводная таблица по сотрудникам (последний замер, уровни цветом,
      дата), внесение за сотрудника, Excel-загрузка с предпросмотром
      и подтверждением (минимум строки: сотрудник + 3 балла + дата).
- [ ] Валидация диапазонов баллов на сервере; уровни вычисляются кодом
      по константам-порогам, в БД не хранятся.
- [ ] Руководителю раздел недоступен (и API возвращает 403).
- [ ] tsc/build, смоук расчёта уровней; db push (новая таблица, аддитивно).

## Открытые вопросы

- Точные диапазоны шкал и пороги уровней русской адаптации MBI —
  подтвердить по странице результата psytests (жду скриншот/текст);
  до подтверждения — стандартные значения Водопьяновой константами.
- Может ли сотрудник удалить/исправить свой замер (или только HR)? —
  предложение: исправлять/удалять может HR; сотрудник — только вносить.
