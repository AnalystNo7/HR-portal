# BRIEF: правила методики v1.2 — категории компетенций и константный целевой уровень
Дата: 2026-07-23

## Формулировка своими словами
Перевести отбор сильных сторон и зон развития на правило методики v1.2: компетенции
с |Δ| ≥ 0,6 — только слепые зоны/скрытые возможности (уже реализовано); остальные
распределяются по «Итоговой (средней)» (среднее групповых средних, включая
самооценку): строго > 3,4 — сильная сторона, строго < 3,0 — зона развития,
3,0–3,4 — никуда. Топ-3 отменяется, количество не ограничено. Целевой уровень —
константа методики 3,0: поле убрать из настроек, сохранённые значения игнорировать.

## Контекст
- Задача №45 уже сделала разделы взаимоисключающими (|Δ| ≥ 0,6 → только зоны).
- Сейчас сильные = топ-3 по оценке окружения, развитие = окружение < целевого;
  целевой уровень настраивается в редактировании цикла (из формы запуска убран ранее).
- «Итоговая (средняя)» уже считается (total в analytics, колонка таблицы).
- Методика v1.2 сконвертирована в .md и передана пользователю для базы знаний.
