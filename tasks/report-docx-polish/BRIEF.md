# BRIEF: Полировка отчёта — подпись шкалы, цвет легенды в DOCX, диаграммы на одном листе

Дата: 2026-08-07

## Формулировка своими словами

Три правки отчёта 360. (1) Подпись «Шкала: 0 — Не могу оценить… · 1 — …»
под сводной таблицей убрать всюду: веб-отчёт, печать/PDF, DOCX и HR-дашборд
«Результаты» — она дублирует опросник и не нужна читателю отчёта; легенда
«Шкала оценок» (менее 2 / 2,0–3,5 / более 3,5) остаётся, фраза «Цветовая
индикация…» ссылается именно на неё. (2) В DOCX легенда «Шкала оценок»
сейчас чёрно-белая — покрасить плашки теми же мягкими цветами, что уже
красят ячейки таблицы (ячейки в DOCX уже цветные). (3) В DOCX две радар-
диаграммы одного сравнения (категории «Ценности» и «Компетенции») сейчас
идут во всю ширину и разъезжаются по листам — ставить их рядом на одном
листе, как в PDF, с подписью категории у каждой.

## Контекст

- Подпись: Report360View.tsx:263-265 (веб+печать), reportDocx.ts:319,
  SubjectPanel.tsx:125 (дашборд).
- Легенда: SCALE в helpers.ts:86-90 (label/cls/desc); DOCX-рендер —
  reportDocx.ts:314 (жирный текст без цвета). Цвета ячеек — scaleBg
  (helpers.ts:100-105): #fbdcdc / #fdf3b3 / #cdf2cd; в DOCX ячейки уже
  красятся (reportDocx.ts:132).
- Диаграммы: captureChart (reportDocx.ts:69) возвращает картинки по
  категориям с их названиями; chartParagraphs (:108) кладёт каждую
  шириной 620 → вторая уезжает на следующий лист. Название категории —
  HTML вне SVG (CategoryRadarCard.tsx:25), в картинку не входит.

## Решения человека (2026-08-07)

- Подпись убрать везде, включая HR-дашборд.
- Диаграммы одного сравнения — рядом (бок о бок) на одном листе, для всех
  блоков: общая, пары самооценки, пары внешних групп.
- Цвета легенды — мягкие, как в ячейках таблицы.

## Критерии успеха

- [ ] Строка «Шкала: 0 — …» отсутствует в веб-отчёте, на дашборде HR,
      в печати/PDF и в DOCX; легенда «Шкала оценок» на месте.
- [ ] В DOCX плашки «менее 2» / «2,0 – 3,5» / «более 3,5» имеют фоновые
      цвета #fbdcdc / #fdf3b3 / #cdf2cd (совпадают с ячейками таблицы).
- [ ] В DOCX диаграммы каждого блока стоят по две в ряд с подписью
      категории над каждой и умещаются на одном листе с заголовком блока.
- [ ] tsc/build фронтенда зелёные; DOCX-смоук (генерация файла) проходит.
