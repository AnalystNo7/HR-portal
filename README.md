# HR-портал

Актуальный код и документация — в ветке `mvp3`; на проде развёрнута ветка `mvp2`.

Корпоративный HR-портал — единая точка входа сотрудника в HR-процессы компании. Личный кабинет с опытом работы и образованием, справочник сотрудников с импортом из Excel и автосозданием учётных записей, обращения к HR с комментариями и файлами, полный цикл оценки 360 — от настройки компетенций до AI-отчёта с выгрузкой в PDF/DOCX — и опросы благополучия (выгорание по методике Маслач).

Целевая аудитория — сотрудники, руководители и HR-служба компании; доступ по ролям через корпоративное SSO.

## Возможности

- **Личный кабинет** — профиль сотрудника: должность, подразделение, руководитель, опыт работы, основное и дополнительное образование
- **Справочник сотрудников** — поиск и фильтры по подразделениям, карточки сотрудников; импорт из Excel с предпросмотром и автосозданием учёток в Keycloak
- **Обращения к HR** — заявки по направлениям со статусами, комментариями, файлами и анонимным режимом; сотрудник видит только свои, HR — все
- **Оценка 360** — версионируемые наборы компетенций и шкал → циклы оценки → опрос респондентов (самооценка, руководитель, подчинённые, коллеги) → результаты с radar-дашбордом и аналитикой зон (консенсус, слепые зоны, скрытый потенциал)
- **AI-отчёт по оценке 360** — генерация интерпретации через LLM по методике, база знаний (PDF/DOCX/MD), поблочная правка HR с удалением/восстановлением блоков, публикация сотруднику, постраничная выгрузка в PDF и DOCX
- **Опросы: выгорание (MBI)** — тест Маслач: сотрудник вносит свои замеры и видит динамику с уровнями и индексом перегорания, HR — сводку по всем с Excel-загрузкой, руководитель — только уровни подчинённых без баллов
- **Администрирование** — сотрудники, подразделения, должности, импорт, пресеты LLM-подключений с проверкой соединения
- **Роли и SSO** — employee / manager / hr / admin через Keycloak, интерфейс и API строго по ролям

## Стек

| Слой | Технологии |
|------|------------|
| Frontend | Next.js 14 (App Router), React 18, TypeScript 5, свой CSS и SVG-графики (без UI-библиотек), docx (генерация DOCX в браузере) |
| Backend | NestJS 10, Prisma 6 + PostgreSQL 16, exceljs, throttler + helmet + class-validator |
| Авторизация | Keycloak 24 (SSO, роли), passport-jwt + JWKS |
| AI | любой OpenAI-совместимый API; пресеты подключений в БД, генерация отчёта по частям (1–8 запросов) |
| Инфраструктура | Docker Compose, Dokploy + Traefik (TLS Let's Encrypt), nginx (локально) |
